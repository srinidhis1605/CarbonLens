**Audit Scope:** `frontend/src/pages/OptimizationPage.js`, `frontend/src/services/v2Service.js`, `backend/services/optimizationService.js`, `backend/routes/v2Optimization.js`, `backend/services/v2DbService.js`, `backend/scripts/generateControlledSite.js`, `research/test-website/original/`, `research/test-website/optimized/`, and the scratch side-by-side preview HTML.

## 2. Verification of Existing Good Controls (Already Present in Codebase)
- `optimizationService.js` already uses `walkFiles()` + `fs.statSync()` to measure `ORIGINAL_DIR` and `OPTIMIZED_DIR` recursively on disk.
- `optimizationService.js` already generates & validates staged files before syncing in-place to `OPTIMIZED_DIR` (preventing Windows `EPERM`).
- `v2Optimization.js` already persists `COMPLETED`, `PARTIAL_SUCCESS`, and `FAILED` runs to MySQL `optimization_runs`.
- `OptimizationPage.js` already clears `activeRun` before starting a new optimization run so an old `COMPLETED` run does not masquerade as a failed current run.
